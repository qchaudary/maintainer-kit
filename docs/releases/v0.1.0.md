# MaintainerKit v0.1.0 - Foundation MVP

Initial open-source release of MaintainerKit.

## Included

- Lightweight command-line interface for repository maintenance workflows.
- Deterministic repository health checks.
- Initial issue classification heuristics.
- Initial pull-request risk and review preparation checks.
- Automated test suite and CI workflows.
- MIT license.
- Contributor, security, governance, and community documentation.

This release establishes the initial MaintainerKit foundation. Later releases build on this baseline with deeper GitHub integration, repository-aware automation, structured outputs, expanded maintainer workflows, and migration to Apache-2.0 licensing.
