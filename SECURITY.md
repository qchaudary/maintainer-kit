# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of MaintainerKit seriously. If you believe you have found a security vulnerability:

1. **Do not disclose it publicly.** Avoid filing a public issue.
2. Email full reproduction details to: **qasim.pointofit@gmail.com**.
3. We will acknowledge receipt within 48 hours and coordinate a fix and advisory release.
